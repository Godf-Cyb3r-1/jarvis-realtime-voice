# Reference voice assets

Keep voice recordings private. Upload `voices.zip` directly to a private Kaggle dataset/notebook input. Extract and convert the English and Tamil MP3 files to 24 kHz mono WAV using ffmpeg, then place `en.wav`, `en.txt`, `ta.wav`, `ta.txt` in this folder on the GPU worker.

These voice recordings are intentionally not committed to this public repository. The reference transcripts are supplied with the original ZIP; do not invent replacement text.
